# java-calculator-precourse
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

## 구현할 기능 목록
- 문자열 분리
  - 쉼표(","), 콜론(":"),커스텀 구분자 기준으로 문자열을 분리한다. 
- 분리된 문자열을 더한다.
  - 문자열을 숫자로 변환한다. 
- 커스텀 구분자를 추가한다.
  - 기본 구분자를 지정할 수 없다. 
  - "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 입출력 요구 사항
### 입력
- 구분자와 양수로 구성된 문자열
### 출력
- 덧셈 결과
```
결과 : 6
```
### 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
